## Datos personales que se recogen

En este sitio web **no se recogen datos personales mediante formularios**, ya que:

- no se permiten comentarios

- no existen formularios de contacto

- no se realizan registros de usuarios

Únicamente se podrán tratar datos personales en el caso de que una persona contacte voluntariamente por correo electrónico.

## Finalidad del tratamiento

Los datos personales facilitados voluntariamente por correo electrónico se utilizarán exclusivamente para:

- responder consultas

- mantener comunicaciones relacionadas con el contenido editorial

No se utilizarán para fines comerciales ni publicitarios.

## Base legal para el tratamiento

La base legal para el tratamiento de los datos es el **consentimiento del interesado**, otorgado al enviar voluntariamente un correo electrónico.

## Conservación de los datos

Los datos se conservarán únicamente durante el tiempo necesario para atender la comunicación y se eliminarán posteriormente, salvo obligación legal en contrario.

## Destinatarios de los datos

No se cederán datos personales a terceros, salvo obligación legal.

## Derechos de las personas interesadas

Las personas interesadas pueden ejercer los siguientes derechos:

- Acceso

- Rectificación

- Supresión

- Limitación del tratamiento

- Oposición

Para ejercer estos derechos, pueden dirigirse al correo electrónico indicado anteriormente.

## Medidas de seguridad

El titular aplica las medidas técnicas y organizativas necesarias para garantizar la seguridad y confidencialidad de los datos personales tratados.
